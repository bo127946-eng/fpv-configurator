/Общая архитектура экосистемы/ [
XFire Ecosystem v3.6 — это передовая аппаратно-программная экосистема для разработки, настройки и пилотирования кастомных беспилотных летательных аппаратов (UAV) класса FPV/квадрокоптеров. 

Основные аппаратные компоненты:
- Полетный контроллер (FC): микроконтроллер STM32 с низкоуровневой детерминированной прошивкой (главной цикл 250 Гц без блокирующих задержек).
- Силовая установка: моторы 2312, пропеллеры 9450, питание 4S LiPo.
- Инерциальные и дальномерные датчики: IMU (MPU6050 / MPU6500), Лазерный дальномер (VL53L1X LiDAR).
- Беспроводной радиоинтерфейс: модуль RTX на чипах Semtech LoRa (SX1262 / SX1268 / Ebyte E22) в диапазоне 915 МГц.
- Пульт управления (RC): кастомный передатчик с поддержкой автокалибровки стиков, переменной скоростью пакетов (1 Гц в покое, 10 Гц в движении) и частотным сканированием.

Приложение реализует полнофункциональный кроссплатформенный интерфейс с поддержкой USB OTG Serial связи, пакетной отправкой конфигураций через CLI-команду `config`, визуальным HUD, авиогоризонтом, калькуляторами радиолинка и геометрии антенн.

/Полетный контроллер (FC) и режимы/ [
Модуль управления динамикой полета дрона и ограничениями безопасности.
Поддерживаемые полетные режимы:
- 0: Acro (чистый мануальный режим без автовыравнивания)
- 1: Angle (автоматическое выравнивание по крену и тангажу)
- 2: Horizon (комбинированный режим с переходом в акро при отклонении стиков)

Параметры и CLI команды:
- fl_mode <0|1|2> — выбор текущего полетного режима.
- fl_roll_max <10..80> — максимальный допустимый угол крена в градусах.
- fl_pitch_max <10..80> — максимальный допустимый угол тангажа в градусах.
- fl_vz_speed_max <0.5..3.0> — максимальная вертикальная скорость подъема/спуска (м/с).
- fl_height_min <0..5.0> — минимальная безопасная высота полета (м).

/Радиоуправление и RC экспоненты/ [
Настройка кривых отклика стиков радиоуправления для тонкой настройки чувствительности в центре и по краям диапазонов.
CLI команды:
- rc_rate <0.1..2.0> — общий коэффициент чувствительности (Roll/Pitch).
- rc_super_expo <0.0..0.9> — коэффициент супер-экспоненты для резких маневров.
- rc_stick_expo <0.0..1.0> — классическая экспонента стиков.
- rc_yaw_rate <0.1..2.0> — скорость вращения по оси Yaw.
- rc_yaw_super_expo <0.0..0.9> — супер-экспонента оси Yaw.
- rc_yaw_expo <0.0..1.0> — экспонента оси Yaw.
- rc_horizon_transition <0.0..1.0> — коэффициент плавности перехода в режиме Horizon.
- rc_deadband <0..50> — мертвая зона стиков в единицах PWM для устранения дрейфа стиков.
- rc_filter_smoothing <0.05..1.0> — коэффициент цифрового сглаживания входящих RC пакетов.
]

/Система аварийной посадки (Failsafe)/ [
Многоуровневая система обеспечения безопасности полета при возникновении внештатных ситуаций или потере связи.
CLI команды:
- rc_fs_en <0|1> — включение реакции на потерю управляющих пакетов с пульта.
- fs_bat_en <0|1> — аварийная посадка при критическом разряде силовой батареи.
- fs_rtx_en <0|1> — аварийный режим при потере связи по радиоканалу RTX.
- fs_spi_en <0|1> — fail-safe при обрыве шины обмена SPI с датчиками/радио.
- fs_i2c_en <0|1> — fail-safe при сбое шины I2C (IMU/LiDAR).
- fs_vz_speed <0.2..2.0> — скорость вертикального аварийного снижения (м/с).
]

/Аварийный резервный канал связи/ [
Управление поведением борта при ухудшении качества радиосигнала и задействование резервных инициатив.
CLI команды:
- rtx_link_warn_threshold <5..90> — порог падения качества связи в процентах (%) для предупреждения/инициативы.
- rtx_auto_en <0|1> — бортовая инициатива автоматической смены канала/мощности при деградации линка.
]

/Питание и батарея (4S LiPo)/ [
Конфигурация параметров питания силовой сборки на базе 4-х баночных (4S) аккумуляторов.
CLI команды:
- bat_cells <1..6> — количество последовательно соединенных ячеек (рекомендуется 4S).
- bat_fs_v <6.0..25.0> — пороговое напряжение срабатывания Failsafe по разряду батареи (В).
- bat_filter_alpha <0.01..1.0> — коэффициент фильтрации пульсаций напряжения питания.
]

/Лидар VL53L1X и дальнометрия/ [
Интеграция лазерного дальномера для точного измерения и удержания малой высоты над землей.
CLI команды:
- lidar_en <0|1> — включение/выключение опроса датчика VL53L1X по I2C.
- lidar_min_alt <0.0..2.0> — минимальная рабочая высота лидара (м).
- lidar_filter_alpha <0.01..1.0> — коэффициент сглаживания показаний дальномера.
]

/Цифровая фильтрация датчиков/ [
Многоступенчатая обработка сигналов с гироскопа и акселерометра для подавления высокочастотных вибраций моторов 2312 и пропеллеров 9450.
CLI команды:
- filter_mode <0..3> — выбор режима фильтрации (0: Off, 1: LPF, 2: Notch, 3: DynNotch).
- gyro_filter_alpha <0.05..1.0> — фильтр низких частот (LPF) гироскопа.
- acc_filter_alpha <0.01..1.0> — фильтр низких частот акселерометра.
- filter_notch_freq <30..250> — центральная частота статического режекторного фильтра (Гц).
- filter_notch_bw <5..50> — ширина полосы режекторного фильтра (Гц).
- filter_dyn_min_hz <30..120> — нижняя граница работы динамического режекторного фильтра (Гц).
- filter_dyn_max_hz <150..350> — верхняя граница работы динамического режекторного фильтра (Гц).
]

/ПИД-регуляторы (Rate & Vz)/ [
Настройка ПИД-контуров стабилизации угловой скорости (оси Roll, Pitch, Yaw) и вертикальной скорости (Vz), оптимизированная под 2312 моторы.
CLI команды:
- roll_kp / roll_ki / roll_kd — коэффициенты ПИД для оси крена (Rate).
- pitch_kp / pitch_ki / pitch_kd — коэффициенты ПИД для оси тангажа (Rate).
- yaw_kp / yaw_ki / yaw_kd — коэффициенты ПИД для оси рыскания (Rate).
- vz_kp / vz_ki / vz_kd — коэффициенты ПИД регулятора вертикальной скорости (Vz).
]

/Радиомодуль RTX (915 МГц) и линк/ [
Параметры беспроводного интерфейса на базе LoRa чипов Semtech SX126x.
CLI команды:
- rtx_en <0|1> — включение радиомодуля.
- rtx_band <1..9> — выбор частотного диапазона (9 = 900 МГц).
- rtx_addr <0..65535> — сетевой адрес устройства.
- rtx_chan <0..99> — рабочий радиоканал (+15 МГц сдвиг = 915 МГц).
- rtx_sf <5..12> — фактор расширения спектра (Spreading Factor).
- rtx_bw <0..9> — полоса пропускания канала (Bandwidth).
- rtx_cr <1..4> — коэффициент кодирования (Coding Rate).
- rtx_power <-9..22> — выходная мощность передатчика в dBm.
- rtx_afc_en <0|1> — автоматическая подстройка частоты (AFC).
]

/Геометрия и расчет антенн/ [
Расчет физических размеров элементов антенн (штыревой диполь и антенна Харченко) под рабочую частоту 915 МГц с учетом защитных термоусадочных трубок и диэлектрической проницаемости.
CLI команды:
- ant_combo_config <0|1> — выбор конфигурации антенн (0: Штырь+Штырь, 1: Харченко+Штырь).
- ant_sleeve_en <0|1> — учет защитного чехла/трубки.
- ant_sleeve_thick <0.5..3.0> — толщина стенки трубки (мм).
- ant_tube_diam <2.0..5.0> — диаметр нижнего плеча диполя (мм).
- ant_top_wire <0.5..2.5> — сечение верхнего проводника (мм²).
- ant_kharc_wire <1.0..4.0> — сечение провода антенны Харченко (мм²).
- ant_fade_margin <5.0..30.0> — запас по затуханию (Fade Margin, dB).
]

/Калибровка и аппаратные тесты/ [
Диагностика и калибровка бортовых сенсоров, моторов и интерфейсов.
CLI команды:
- cal_gyro — запуск калибровки нулевого смещения гироскопа.
- cal_acc — запуск калибровки уровня акселерометра.
- cal_lidar — калибровка нулевой отметки лазерного дальномера.
- test_mpu — проверка связи и ответа IMU MPU6050 по I2C.
- test_sx — проверка SPI-соединения с LoRa радиомодулем SX126x.
- test_lidar — проверка отклика лазерного дальномера.
- test_motor — кратковременный тестовый запуск моторов на 2312 (25% тяги).
- test_pid — стресс-тест отработки ПИД-контуров.
- test_rc — диагностика входящих управляющих пакетов пульта.
- test_rc_can — автопоиск и смена рабочего радиоканала связи с пультом.
]

/Системные команды и пакетная конфигурация/ [
Управление сеансом связи по USB Serial и пакетная запись параметров.
CLI команды:
- info — вывод текущей конфигурации и состояния системы в терминал.
- mon — запуск потоковой передачи телеметрии (гироскоп, акселерометр).
- stop — остановка потоковой передачи телеметрии/мониторинга.
- config \n "par1\npar2\n..." — универсальная команда многострочной пакетной передачи настроек за один сеанс связи.
]

/Прошивка устройств/ [
Обновление встроенного программного обеспечения микроконтроллеров полетного контроллера (STM32) и пульта управления (v3.6).
CLI команды:
- flash_fc — запуск процесса прошивки полетного контроллера (поддерживается через интерфейс приложения с отображением прогресс-бара).
- flash_rc — запуск процесса обновления прошивки пульта управления.
]
